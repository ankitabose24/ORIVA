ORIVA — Healthy Can Be Tasty 🌿

Industry: Healthy Food / Breakfast & Snacks
Objective: A modern, story-driven healthy food website created around the idea that nutritious food can also be tasty, affordable, colourful, and enjoyable. ORIVA brings together fresh fruits, wholesome bowls, healthy breakfast options, refreshing drinks, and smart snacks in an interactive one-page experience.

Live Demo: [https://oriva-delta.vercel.app/](https://oriva-delta.vercel.app/)

About ORIVA

ORIVA is a coined brand name created for a healthy food and breakfast concept.

The name can be interpreted as:

Ori → Origin / fresh beginning
Viva → Life, energy, and vitality

Together, ORIVA represents the idea of a fresh beginning for a healthier life.

The website is designed to move away from the idea that healthy food has to be boring or expensive. It presents food through attractive imagery, simple nutritional information, benefits, categories, and an easy ordering experience.

ORIVA — A fresh beginning for a healthier life.

Technologies Used
HTML5 — semantic structure for the complete single-page website and its different content sections
CSS3 — custom colour palette, responsive layouts, typography, food cards, navigation, hero slider, modal styling, cart panel, animations, and mobile adaptations
JavaScript (ES6+, Vanilla JS) — food rendering, category filtering, hero flyer slider, food-detail popup, cart functionality, quantity controls, mobile navigation, toast messages, and interactive UI behaviour
Google Fonts — Playfair Display and DM Sans for a clean editorial food aesthetic
Unsplash / Food Photography — used for food and lifestyle imagery where applicable

## Sections

1. **Hero** — Full-screen food visuals with ORIVA branding, healthy-food messaging, and flyer slider.

2. **Why Choose ORIVA?** — Highlights fresh ingredients, nutrition, variety, portions, and affordable healthy choices.

3. **Food Categories** — Browse food through categories like Fresh Fruits, Bowls, Breakfast, Drinks, and Smart Snacks.

4. **Food Collection** — Displays healthy dishes with images, descriptions, prices, and nutritional information.

5. **Food Details** — Interactive popup showing a dish's image, benefits, protein, fibre, calories, price, and preparation time.

6. **Healthy Breakfast & Bowls** — Showcases wholesome breakfast and filling bowl options.

7. **Healthy Drinks** — Features refreshing smoothies, coolers, and nutritious beverages.

8. **Smart Snacks** — Offers convenient and healthier snack choices for everyday cravings.

9. **Shopping Cart** — Allows users to add items, manage quantities, and view the total price.

10. **Responsive Experience** — Ensures the website works smoothly across desktop, tablet, and mobile devices.

## File Description

* **`index.html`** — Contains the complete structure and content of the ORIVA website.

* **`style.css`** — Contains the website styling, layout, colours, typography, responsive design, and animations.

* **`script.js`** — Handles interactive features such as food filtering, food details popup, hero slider, cart, quantity controls, and navigation.

* **`README.md`** — Contains project documentation, features, technologies, setup instructions, and design details.

How to Run

Open `index.html` directly in any modern browser, or serve the folder locally:

```bash
npx serve .
```
You can also use VS Code Live Server:

Open the project folder in VS Code.
Install the Live Server extension.
Right-click `index.html`.
Select Open with Live Server.
The website will open in your browser.

Project Goals

The main goals of ORIVA are to:

Present healthy food in an attractive way.
Show that nutritious food can also be enjoyable.
Make nutritional information easy to understand.
Provide different breakfast and snack choices.
Create an interactive food-browsing experience.
Keep the interface simple and responsive.
Demonstrate modern frontend development using vanilla HTML, CSS, and JavaScript.

ORIVA is a healthy breakfast and snacks website built around a simple idea:

Healthy can be tasty.

Instead of presenting nutritious food as something restrictive or complicated, ORIVA creates an experience where visitors can explore colourful dishes, understand basic nutritional information, discover food benefits, and build a simple cart.

Built entirely with HTML5, CSS3, and vanilla JavaScript, the project remains lightweight while providing interactive elements such as food filtering, detailed food popups, a hero flyer slider, cart functionality, quantity controls, and responsive navigation.
